# Member Legacy

The public website for Member Legacy, rebuilt as a fast, accessible Next.js application for deployment on Vercel.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production checks

```bash
npm run typecheck
npm run build
```

## Deployment

Import this repository into Vercel and accept the detected Next.js settings. No environment variables are required for the current site.

The ROI calculator is a transparent scenario model. It does not persist visitor data or represent a guarantee of program performance.
